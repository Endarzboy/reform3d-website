Evaluation protocol

Frozen encoders. Complementary measurements.

REFORM-3D examines representation quality on KiTS23 and MMWHS. Each module measures a distinct property, with results reported separately rather than combined into a single ranking.

Datasets and primary evaluation metrics
Module Dataset Measurements
Spacing sensitivity KiTS23 Embedding drift, CKA, matched semantic transfer
Cross-modal alignment MMWHS CT–MR retrieval: mAP, Top-1, Top-5
Anatomical generalization MMWHS Centroid and probe balanced accuracy, adaptation gain

Encoders remain frozen throughout evaluation. Low-shot probes fit labeled readouts using case-disjoint support and query sets. Configure checkpoints, feature readouts, and seeds explicitly.

From inputs to evidence

Configure. Check. Evaluate.

Start with Python 3.11 on Linux and a PyTorch build compatible with your CUDA installation. Install REFORM-3D, then edit the dataset and checkpoint paths in the example YAML.

The MMWHS example evaluates cross-modal retrieval and low-shot recognition. Use the KiTS23 example for controlled spacing evaluation.

Full installation instructions ↗
1. Install · Linux / bash 
git clone https://github.com/Endarzboy/REFORM3D.git
    cd REFORM3D
    python3.11 -m venv .venv
    source .venv/bin/activate
    python -m pip install -c requirements.txt .
2. Run · after editing YAML paths 
reform3d check --config configs/mmwhs-demo.yaml
    reform3d run --config configs/mmwhs-demo.yaml

These measurements support a task-specific encoder shortlist; they do not guarantee a downstream winner. Low-shot probes fit labeled readouts while the encoder remains frozen.
